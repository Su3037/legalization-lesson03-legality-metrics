Legalization · Lesson 03 · 合法性检查与指标

合法吗？

全局布局给了每个单元一个坐标。这张布局能直接交给下一步吗？先学会判断它合不合法，再学怎么比较两个都合法的结果。

约 60 分钟 · 4 部影片 · 实验台 · 10 个挑战 · Python 练习 · 改编自 yongfu-li/eda-learning Module 01-03（CC BY 4.0）

前置
知道标准单元、行和全局布局在做什么；会读简单的伪代码。
例子
芯片 12 × 6，三行，六个单元（D 固定），六个线网。
规则
在行上 · 对齐站点 · 整个在芯片内 · 同行不重叠 · 固定单元不动

位移（总和、平均、最大）· 半周长线长 HPWL
验证
CP-SAT 精确最优 · OpenROAD check_placement · 18 个变异体

01 / 目标与问题

学完能做什么

  1. 说出一张标准单元布局合法的五条规则，并对任意布局逐条判断。
  2. 写出一个检查器：先校验输入，再列出全部违规，而不只是第一条。
  3. 用左闭右开的区间判断重叠，分清“相接”和“重叠”。
  4. 从一张固定的参考布局计算位移（总和、平均、最大），用单元中心计算 HPWL。
  5. 比较两个合法的修复结果时，先说清楚比的是哪个指标；知道最优常常不唯一。
  6. 说出玩具检查器和真实签核工具之间还差哪些检查。

问题是什么

输入

芯片、行（底边 y、行高）、站点宽；单元宽高；固定声明；线网；一张布局（左下角坐标）。

输出

结论（合法 / 不合法 / 输入无效）、全部违规清单，以及位移和 HPWL。

约束

五条规则同时成立。区间 [x, x + w) 左闭右开，相接可以。

目标

先合法，再比分数：位移小，线长短。分数救不了不合法的布局。

假设

单元都是一行高；坐标是左下角；行和站点均匀；线网的引脚取单元中心。

停止

输入无效时立即停止，不做几何检查；否则查完每个单元和同行的每一对。

03 / 讲解

五条规则、一个检查器、两个指标

每张图都由实验台用的同一个检查器判定，图下的标签就是它的结论。下载 Markdown 大纲

03.1

行、站点、坐标、区间

本课的芯片宽 12、高 6，分成三行，每行高 2，行的底边在 y = 0、2、4。每一行又切成宽 1 的站点。单元的坐标指它的左下角。所以 A 在 (4, 2)，意思是它从第 4 格开始，占住 4 到 6 这一段。我们把这一段写成左闭右开的区间 [4, 6)：4 算在里面，6 不算。

行（háng）· 站点 · 锚点 · 区间

行是单元可以落脚的水平带；站点是行里宽 1 的格子；锚点是单元左下角；区间 [x, x + w) 是单元在行里占的长度。

03.2

五条规则

一张布局合法，当且仅当下面五条同时成立，并且输入完整（见 03.3）。

规则一：在行上

单元的底边必须正好落在某一行的底边上。

规则二：对齐站点

x 减去第一个站点的位置，必须是站点宽的整数倍。差半格也不行。

规则三：整个单元在芯片内

看整个矩形，不只是左下角：x ≥ 0，x + w ≤ W，y ≥ 0，y + h ≤ H。

规则四：相接可以

a.x + a.w = b.x 时两个区间没有共用任何长度，合法。

规则四：同行不重叠

a.x < b.x + b.w 且 b.x < a.x + a.w 才算重叠。B 往左挪一格就共用了 1 格。

规则五：固定单元不能动

D 被声明为固定，就必须待在 (8, 4)。挪到空地上也算违规。

同一张布局，关掉固定约束

固定声明是输入的一部分：问题变了，答案也跟着变。实验台上可以切换开关对比。

03.3

检查器：第一条错误和全部错误

把五条规则合在一起，就是一个完整的检查器。它先确认输入是完整的：少了单元、多了没声明的单元、坐标不是有限的数、线网或固定声明里出现了没声明的单元，都直接判为输入无效，不再做几何检查，也不会替未知单元编一个默认宽度。然后它逐个单元、逐对单元地检查，把每一条违规都记下来。

0  输入：芯片、单元、线网、固定声明；布局；参考布局
1  若输入不完整或有非法数值 → 输入无效，停止
2  对每个单元 c：
3    若 c.y 不是任何一行的底边 → 记 ROW
4    若 (c.x − x0) 不是站点宽的整数倍 → 记 SITE
5    若 c 的整个矩形不在芯片内 → 记 BOUNDS
6    若 c 是固定单元且坐标变了 → 记 FIXED
7  对同一行里的每一对单元 (a, b)：
8    若 [a.x, a.x+a.w) 与 [b.x, b.x+b.w) 相交 → 记 OVERLAP
9  合法 ⇔ 一条记录都没有；第一条记录 = 最先发现的错误
10 位移 = Σ |x−x参考| + |y−y参考|；HPWL = Σ 线网中心包围盒的宽 + 高

回到开场的布局：第一条错误是 A 和 B 重叠，但完整的清单有三条（A/B、A/C、B/C）。只报第一条的检查器会让人修了一处又冒出一处；本课的检查器两样都给。实验台的“逐步检查”会一行一行高亮上面的伪代码。

开场布局

A、B、C 挤在中间一行的同一个位置：三条 OVERLAP。

坐标在内部换成整数：检查器把所有坐标乘以 1000（数据库单位，DBU）再比较，只有离整数不到 10−6 时才取整。站点宽是 0.19 之类的非整数时，“对齐站点”也能精确判断，不会因为浮点误差把 0.57 判成没对齐。

03.4

取整不等于合法

把坐标四舍五入，不就合法了吗？全局布局给的是小数，取整以后每个单元都对齐了站点，也都落在行上。可是 A 和 B 还是叠在一起。取整只解决了对齐，没有解决重叠。

只取整

每个单元都在行上、对齐站点，但仍然重叠。

03.5

两个指标：位移与半周长线长

位移：每个单元算它离参考位置的 |Δx| + |Δy|，再把所有单元加起来；检查器同时报告总和、平均值和最大值。参考位置要先说清楚，而且中途不能换：如果每挪一次就把参考换成当前布局，第二次挪动就会把第一次的账抹掉。实验台上的参考布局只有在你明确点“设为新参考”时才会改变。

半周长线长（HPWL）：取线网里每个单元的中心，框出最小的矩形，宽加高就是这个线网的 HPWL；所有线网加起来就是总 HPWL。用中心而不是左下角，宽度不同的单元才算得公平。只连一个单元的线网，HPWL 为 0。

位移 = Σ |Δx| + |Δy|

参考布局不变，箭头是每个单元离参考的距离。

HPWL = 包围盒的宽 + 高

白点是单元中心，虚线框是线网 {A, B, C, D} 的包围盒。

指标只是诊断。不合法的布局也会算出位移和 HPWL，但会标明“不合法”；分数再好，也不能把不合法变成合法。

03.6

会改变数字的约定

同一张布局，换一个约定，数字就会变。比较两篇论文或两个工具的数字之前，先对齐这些约定。

选择本课其他常见做法
几何与位移的锚点左下角中心（单元尺寸不变时位移相同）
HPWL 的引脚位置单元中心左下角（本系列前一课）；LEF 里真实的引脚偏移（gcd 演示）
位移的度量曼哈顿距离求和平均值、最大值、欧氏距离平方（Abacus）
固定单元算不算位移算（正确时贡献 0）不算（平均值的分母会变）
单位芯片单位（站点）DEF 数据库单位（Nangate45 中 2000 DBU = 1 µm）
相接算不算重叠不算（左闭右开）闭区间会把相接误判为重叠
03.7

修复演示与精确最优

现在来修开场那张布局。第一种办法，把这一行里的单元依次往右推：B 挪到 6，C 挪到 8，位移一共 6，HPWL 32。第二种办法，把 B 和 C 分别挪到上下两行：位移只有 4，HPWL 却变成 38。两个都合法。位移更小的那个，线长反而更长：说“更好”之前，要先说清楚比的是哪个指标。

行内依次推开

位移 6，HPWL 32，合法。

挪到上下两行（Abacus-lite）

位移 4，HPWL 38，合法。

那 4 是不是最少的？我们用精确求解器（OR-Tools CP-SAT）在同样的规则下求最少总位移：

起点（参考）最少总位移最小的最大位移最优摆法数行内推开Abacus-liteAbacus只取整
开场重叠布局（D 固定）4248644不合法
全局布局小数坐标（D 固定）5.41.518.85.86.4不合法

在开场布局上，最少就是 4，而且有 48 种不同的摆法都能做到：挑战按“是否合法、位移是否达到目标”判分，而不是和某一张标准答案比对。从小数出发时，启发式方法会比最优多挪一些。表里的 Abacus 是 Spindler 等人 2008 年方法的一个小而忠实的实现，Abacus-lite 是教师材料里的简化版本。

03.8

总和与最大值

位移的总和也不是唯一的说法。看这一行：X 掉在了 A 上面。让 X 一步跳到右边，总共挪 4，可是 X 一个人就挪了 4。让四个小单元各让 2 格，总共挪 8，但每个单元最多只挪 2。

一步跳开

总和 4，最大 4。

各让 2 格

总和 8，最大 2。

精确求解器给出：这一行的最少总位移是 4，这时最大位移是 4；最大位移最少可以压到 2，这时总位移至少是 6。两者不能同时达到，所以有的比赛和工具会同时看平均值和最大值（ICCAD 2017 合法化比赛对最大位移设了限制；这一条来自文献，比赛网站在构建环境里无法访问，见来源核查）。

03.9

真实检查器还查什么

这个检查器很小。真正的签核工具要查的更多，本课都没有检查：朝向与行匹配（电源轨对齐）、限定区域与禁止放置区、单元间距与边缘规则、多行高单元、引脚可达与填充。

我们在 OpenROAD 自带的 gcd 小设计（Nangate45，461 个单元，57 行）上试过：

布局本课检查器OpenROAD check_placement是否一致
全局布局结果不合法：347 个单元不在行上 / 没对齐站点FAIL：347 个站点对齐错误，237 个重叠站点集合一致；OpenROAD 的 237 个重叠全部被找到，多出的 23 个是它只报了另一方的配对单元
详细布局结果合法PASS一致
注入三处错误恰好三条：SITE、ROW、OVERLAPFAIL：同样三处一致

在两边都检查的规则上，两者结果对得上。我们用的 OpenROAD 版本（2.0-12381）的 check_placement 不检查朝向，这一点由变异测试 M16 确认。

09 / 易错点

八个常见误区

每一条都有一道挑战和一道自测题专门对付它。反例的结论都来自检查器。

I1 · 取整就交出去

取整只解决对齐，不解决重叠。开场小数坐标取整后 A(4,2)、B(4,2)、C(5,2)：OVERLAP ×3。取整之后还要去重叠，并重新检查。

I2 · 只看左下角在不在芯片里

规则三看整个矩形。D 宽 2 放在 x = 11：BOUNDS D。检查 x + w ≤ W、y + h ≤ H。

I3 · 把相接当成重叠

用闭区间的检查器会把合法布局判错。A [0,2) 与 B [2,4) 合法；用 a.x < b.x + b.w 且 b.x < a.x + a.w。

I4 · 没看到重叠就说合法

五条规则要同时成立，而且输入要先完整。只给 A 的坐标：输入无效（V_MISSING），不是“合法”。

I5 · HPWL 更小就交那一张

指标只在合法布局之间比较。开场布局 HPWL 32 却不合法；Abacus-lite 的 HPWL 38，但合法，只能交后者。

I6 · 每挪一步就从上一步算位移

参考布局要固定。B 从 4 挪到 6 再到 8：位移是 4，不是 2。参考只在明确声明时更换。

I7 · 启发式给出的就是唯一最优

最优要用精确方法确认，而且常常不唯一：开场布局最少位移 4，有 48 种摆法。

I8 · 玩具检查器通过就能签核

真实工具还查朝向、区域、间距、多行高单元。本课检查器不看朝向；我们用的 OpenROAD 版本也不看（变异体 M16）。

这一课的边界

  • 单元都是一行高，行和站点均匀；不处理朝向、限定区域、禁止放置区、间距规则和多行高单元。
  • HPWL 用单元中心代替真实引脚位置；gcd 演示里才用 LEF 的引脚偏移。
  • 精确最优只在这一课的小例子上求得；真实规模的合法化不会去求精确最优。
  • 旁白是开源合成声音（Kokoro），不是真人录音。读音按发音词表校正过，但用三个识别模型回听，字错误率仍有 4–5%，高于我们定的 3% 门槛；以字幕和文字稿为准。详见验证页。
