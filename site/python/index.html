自测结果的三种状态

状态意思
PASS24 个用例全对。
INCOMPLETE还没有算错的，但还有函数没写（会列出函数名）。
FAIL至少一个用例算错，脚本会打印期望值和你的结果。

要写的函数

  1. validate：空布局、缺单元、多了未声明的单元、坐标不是有限的数 → 输入无效。
  2. on_row、on_site、inside：规则一到三，坐标换成整数 DBU 再比较。
  3. intervals_overlap：左闭右开，相接不算重叠。
  4. displacement：相对不变的参考布局，总和、平均值、最大值。
  5. hpwl：单元中心的包围盒，宽 + 高，求和。
$ python check.py
  ok    seed: three cells stacked
  ok    legal golden placement
  FAIL  touching cells are legal: verdict 'illegal', expected 'legal'; ...
  ...
FAIL: 21 passed, 3 failed, 0 not implemented

上面这个 FAIL 例子来自一个把区间写成闭区间的实现：相接的 A、B 被误判为重叠。用例里有三个站点宽 0.19 的布局，直接用浮点数比较也会 FAIL。
