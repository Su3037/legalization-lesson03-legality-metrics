旁白：用的是什么声音，有什么不足

《精讲》和《实验演示》两部影片有旁白，是开源合成声音 Kokoro（multi-lang v1.1，说话人 20，Apache-2.0），按整段合成（每一章一段，不是一句一句拼起来的），并把课程的发音词表（“行”读 háng、“重叠”读 chóng dié、HPWL 读“半周长线长”等）写进它自己的词典。字幕时间取自这段录音里真实的停顿位置。

它没有通过我们事先定的客观门槛：用三个独立的语音识别器回听，字错率是 4.3–5.0%，门槛是 ≤ 3%。剩下的错误多数是同音词（如“只是”被听成“指示”）和英文字母、数字的读法。所以：画面里的字幕和下面的文字稿以文字为准；旁白始终标明是合成的；我们不会克隆任何人的声音，除非本人书面同意。提示词里推荐的较新模型（CosyVoice3、Qwen3-TTS、VoxCPM2 等）需要从 Hugging Face 下载，本环境无法访问，也没有付费语音服务的密钥。

升级路径：盲听测试页已经就绪。只要有声音（包括真人录音）通过母语听众盲听，就替换音轨，影片时钟会按新录音的实际时长重新生成。

配乐：《科普》按作者授权使用的曲目 We Never (Remix)（若如初见）· Hi Noise / 秋成 剪辑，录音不在仓库里；其余三部的配乐是 scripts/music.py 用 NumPy 生成的原创音乐，旁白下再压低 9 dB。混音响度：《科普》−17 LUFS，《精讲》−18.1 LUFS，《实验演示》−18.6 LUFS，真峰值都低于 −1 dBTP；《进阶》只有配乐，−22 LUFS。

声音修正词典字错率（Paraformer / SenseVoice / Whisper）声调拼音错误率有声语速（字/秒）

剩下的错误多数是识别器把同音词听错（如“只是”听成“指示”）。我们修正了所有开源词典里把“一行”读成 yì xíng 的错误。合成声音一律会标明是合成的；不会克隆任何人的声音，除非本人书面同意。
